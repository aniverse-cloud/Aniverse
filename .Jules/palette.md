## 2024-05-24 - Custom Circular Button Ripple Bleed
**Learning:** When creating custom circular buttons in Jetpack Compose using a `Column` or `Box` with `Modifier.clickable` and a child `Surface(shape = CircleShape)`, the default ripple effect originates from the parent `clickable` modifier, which assumes a rectangular shape. This causes the ripple to "bleed" out of the circular bounds.
**Action:** Always configure custom `clickable` modifiers for circular elements with `interactionSource = remember { MutableInteractionSource() }` and `indication = null` to suppress the rectangular bleed, and ensure touch feedback is handled by the appropriately shaped child element (like `Surface`), while retaining accessibility by adding `role = Role.Button`. Use standard `IconButton` when simply wrapping an `Icon` to get circular ripples and proper 48dp minimum touch targets out of the box.
